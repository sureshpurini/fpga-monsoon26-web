FPGA-based Accelerator Design

Designing high-performance kernels with High-Level Synthesis

How can a high-level language like C be used to generate efficient hardware datapaths? We build a series of HLS kernels of increasing complexity, looking at what happens under the hood, where performance stalls, and how to address it.

Instructor: Suresh Purini

01 — Overview

About the Course

Special-purpose accelerators are how computing keeps scaling as general-purpose gains slow. This course teaches you to design them productively — writing kernels in C/C++ and using High-Level Synthesis to turn them into fast hardware on an FPGA.

We start from the simplest useful kernel and raise the complexity one obstacle at a time: pipelining and the initiation interval, memory banking and on-chip reuse, dataflow and streaming, and spatial architectures such as systolic arrays. Everything is hands-on: builds run on the department's cluster and execute on real FPGA hardware.

The one idea: a CPU streams a computation through fixed hardware over time; an FPGA lays that same computation out in space. HLS is the compiler that turns your C into that spatial layout — and this course is about learning to guide it.
