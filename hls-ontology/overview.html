HLS Ontology Overview

This ontology provides a comprehensive knowledge base for Vitis HLS code generation and optimization.

What is HLS?

High-Level Synthesis (HLS) converts C/C++ code into hardware description (RTL) that can run on FPGAs. The key challenge is guiding the synthesis tool to produce efficient hardware through pragmas and coding patterns.

Ontology Structure

schema/
├── pragmas.yaml         # All HLS directives
├── types.yaml           # HLS-specific data types

Core Concepts

1. Pragmas

Pragmas are directives that guide HLS synthesis:

#pragma HLS PIPELINE II=1      // Pipeline a loop
#pragma HLS DATAFLOW           // Enable task parallelism
#pragma HLS INTERFACE m_axi    // Memory interface
#pragma HLS ARRAY_PARTITION    // Parallel array access

See: schema/pragmas.yaml

2. Types

HLS provides specialized types for hardware:

Type Purpose
hls::stream<T> Streaming channels
hls::vector<T,N> SIMD vectors
ap_int<W> Arbitrary precision integers
ap_fixed<W,I> Fixed-point numbers

See: schema/types.yaml

3. Interfaces

Hardware interfaces connect the kernel to memory and host:

Interface Use Case
m_axi Memory access (DDR, HBM)
s_axilite Control registers, scalars
axis Streaming data

See: schema/interfaces.yaml

Quick Reference

Dataflow Pattern (Diamond)

void diamond(data_t* in, data_t* out) {
    data_t c1[N], c2[N], c3[N], c4[N];
#pragma HLS DATAFLOW
    funcA(in, c1, c2);   // Fork
    funcB(c1, c3);       // Path 1
    funcC(c2, c4);       // Path 2
    funcD(c3, c4, out);  // Join
}

Streaming with hls::stream

void process(hls::stream<data_t>& in, hls::stream<data_t>& out) {
#pragma HLS INTERFACE axis port=in
#pragma HLS INTERFACE axis port=out
    while (!in.empty()) {
        data_t val = in.read();
        out.write(val * 2);
    }
}

Memory Interface

void kernel(data_t* mem_in, data_t* mem_out, int size) {
#pragma HLS INTERFACE m_axi port=mem_in depth=1024
#pragma HLS INTERFACE m_axi port=mem_out depth=1024
#pragma HLS INTERFACE s_axilite port=size
#pragma HLS INTERFACE s_axilite port=return
    // ...
}
