Perfect Loop Restructuring

Restructure imperfect loop nests into perfect loop nests to enable LOOP_FLATTEN and eliminate pipeline bubbles between outer loop iterations.

Overview

Perfect loop: All code is inside the innermost loop body. Imperfect loop: Code exists between loop levels (before/after inner loop).

IMPERFECT (pipeline bubbles):          PERFECT (continuous flow):
┌─────────────────────────────┐        ┌─────────────────────────────┐
│ for (i) {                   │        │ for (i) {                   │
│   acc = 0;       ◄── GAP    │        │   for (j) {                 │
│   for (j) {                 │   ──►  │     if (j == 0) acc = 0;    │
│     acc += A[j];            │        │     acc += A[j];            │
│   }                         │        │     if (j == N-1) B[i]=acc; │
│   B[i] = acc;    ◄── GAP    │        │   }                         │
│ }                           │        │ }                           │
└─────────────────────────────┘        └─────────────────────────────┘

Key Constructs

Construct Purpose
if (j == 0) Replace pre-loop initialization
if (j == N-1) Replace post-loop processing
#pragma HLS LOOP_FLATTEN Merge perfect nested loops into single loop
#pragma HLS PIPELINE Pipeline the innermost (or flattened) loop

Syntax

for (int i = 0; i < M; i++) {
#pragma HLS LOOP_FLATTEN  // Only works with perfect loops
    for (int j = 0; j < N; j++) {
#pragma HLS PIPELINE II=1
        if (j == 0)              // First iteration of inner loop
            acc = 0;

        acc += A[j] * i;         // Core computation

        if (j == N-1)            // Last iteration of inner loop
            B[i] = acc / N;
    }
}
Boundary Check Replaces
if (j == 0) Code before inner loop
if (j == N-1) Code after inner loop

Complete Example

From Pipelining/Loops/perfect_loop/loop_perfect.cpp:

#include "loop_perfect.h"

void loop_perfect(din_t A[N], dout_t B[N]) {
    int i, j;
    dint_t acc;

LOOP_I:
    for (i = 0; i < 20; i++) {
    LOOP_J:
        for (j = 0; j < 20; j++) {
            if (j == 0)              // Replaces: acc = 0; before LOOP_J
                acc = 0;
            acc += A[j] * j;
            if (j == 19) {           // Replaces: code after LOOP_J
                if (i % 2 == 0)
                    B[i] = acc / 20;
                else
                    B[i] = 0;
            }
        }
    }
}

hls_config.cfg:

syn.directive.pipeline=loop_perfect/LOOP_J

Variants

Variant 1: Pipeline Inner Loop (Default)

Inner loop iterations overlap; outer loop is sequential.

LOOP_I:
    for (int i = 0; i < M; i++) {
    LOOP_J:
        for (int j = 0; j < N; j++) {
#pragma HLS PIPELINE II=1  // Pipeline inner
            // ... perfect loop body ...
        }
    }

Cycles: M x N + pipeline_depth Resources: 1x loop body Array access: Sequential

Variant 2: Pipeline Outer Loop (Unrolls Inner)

All inner iterations execute in parallel.

LOOP_I:
    for (int i = 0; i < M; i++) {
#pragma HLS PIPELINE II=1  // Pipeline outer - unrolls inner!
    LOOP_J:
        for (int j = 0; j < N; j++) {
            // ... perfect loop body ...
        }
    }
#pragma HLS ARRAY_PARTITION variable=A complete dim=1  // Required!

Cycles: M + pipeline_depth Resources: Nx loop body Array access: N parallel accesses (requires partitioning)

Variant 3: Flattened Loop

Merge into single loop of M*N iterations.

LOOP_I:
    for (int i = 0; i < M; i++) {
#pragma HLS LOOP_FLATTEN
    LOOP_J:
        for (int j = 0; j < N; j++) {
#pragma HLS PIPELINE II=1
            // ... perfect loop body ...
        }
    }

Benefit: Eliminates all loop overhead, continuous pipeline flow.

Code Generation Guidelines

Kernel Template

void kernel(din_t A[N], dout_t B[M]) {
#pragma HLS PIPELINE         // Or on specific loop
// #pragma HLS LOOP_FLATTEN  // If perfect loop

    dint_t acc;

OUTER:
    for (int i = 0; i < M; i++) {
    INNER:
        for (int j = 0; j < N; j++) {
            // BOUNDARY: First iteration setup
            if (j == 0)
                acc = initial_value;

            // CORE: Main computation
            acc = update(acc, A[j], i, j);

            // BOUNDARY: Last iteration teardown
            if (j == N-1)
                B[i] = finalize(acc);
        }
    }
}

Transformation Steps

  1. Identify pre-inner-loop code (runs once per outer iteration)
  2. Move inside inner loop, guard with if (inner_index == 0)
  3. Identify post-inner-loop code
  4. Move inside inner loop, guard with if (inner_index == last)
  5. Verify no code remains between loop headers
  6. Apply #pragma HLS LOOP_FLATTEN if desired

Key Constraints

Constraint Requirement
Loop structure All code inside innermost loop
Boundary checks Must be compile-time evaluable
Loop bounds Should be compile-time constants for LOOP_FLATTEN
Init pattern Use conditional reset, not pre-loop assignment

Required Pragmas

Pragma Required? Purpose
#pragma HLS PIPELINE Yes Pipeline the loop iterations
#pragma HLS LOOP_FLATTEN Optional Merge nested loops
#pragma HLS ARRAY_PARTITION If outer pipeline Enable parallel access

Test Bench Generation Guidelines

Test Bench Template

#include "kernel.h"
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    din_t A[N];
    dout_t B[M];
    dout_t B_golden[M];

    // Initialize inputs
    for (int i = 0; i < N; i++)
        A[i] = (din_t)i;

    // Compute golden reference (C model)
    for (int i = 0; i < M; i++) {
        dint_t acc = 0;
        for (int j = 0; j < N; j++)
            acc += A[j] * j;
        B_golden[i] = (i % 2 == 0) ? acc / N : 0;
    }

    // Execute DUT
    kernel(A, B);

    // Verify
    int errors = 0;
    for (int i = 0; i < M; i++) {
        if (B[i] != B_golden[i]) {
            cout << "Mismatch at " << i << ": " << B[i]
                 << " vs " << B_golden[i] << endl;
            errors++;
        }
    }

    if (errors == 0) {
        cout << "Test PASSED" << endl;
        return 0;
    }
    cout << "Test FAILED with " << errors << " errors" << endl;
    return 1;
}

Optimization Guidance for Agents

When to Apply This Pattern

Decision tree:
├── Nested loop with code between levels?
│   ├── Yes → Restructure to perfect loop
│   │         ├── Pre-loop init? → if (j == 0)
│   │         └── Post-loop code? → if (j == last)
│   └── No → Already perfect, consider LOOP_FLATTEN
├── Want to flatten loops?
│   ├── Yes → Ensure perfect structure, add LOOP_FLATTEN
│   └── No → Just pipeline inner loop
└── Pipeline inner or outer?
    ├── Inner (default): Sequential, low resources
    └── Outer: Parallel, high resources, needs partition

Performance Optimization

Optimization How to Apply Expected Impact
Perfect restructuring Move init/teardown inside with conditionals Eliminates pipeline bubbles
LOOP_FLATTEN Add pragma after restructuring Single flattened loop, no overhead
Pipeline inner Default choice M*N cycles, 1x resources
Pipeline outer Add ARRAY_PARTITION M cycles, Nx resources

Resource vs Performance Trade-offs

Choice Performance Impact Resource Impact
Imperfect + inner pipeline Pipeline bubbles between outer iters Minimal
Perfect + inner pipeline Continuous flow Minimal
Perfect + LOOP_FLATTEN Optimal flow Minimal
Perfect + outer pipeline Nx throughput Nx resources

Parameter Tuning

Parameter Low Value High Value Guidance
Pipeline location Inner loop Outer loop Inner=low resource, Outer=high throughput
LOOP_FLATTEN Off On Enable for perfect loops with constant bounds

Common Pitfalls

Pitfall Symptom Solution
Code between loops Cannot LOOP_FLATTEN Restructure with boundary conditionals
Variable loop bounds LOOP_FLATTEN fails Use constants or remove flatten
Pipeline on outer without partition II violations Add ARRAY_PARTITION
Last index off-by-one Wrong boundary behavior Use j == N-1 not j == N
