Quick Reference

Channel Selection

Need random access within data unit?
├── No → Use FIFO
│        ├── hls::stream<T> (explicit, recommended)
│        └── data_t arr[N] + #pragma HLS STREAM
└── Yes → Need streaming between units?
    ├── No → Use PIPO (just data_t arr[N])
    └── Yes → Use stream_of_blocks

Interface Selection

What type of data?
├── Large array/buffer
│   ├── Accessed once, sequentially → axis
│   └── Random access or reuse → m_axi
├── Scalar value → s_axilite
└── Control signals → s_axilite port=return

Loop Optimization

Should I pipeline or unroll?
├── Usually: Pipeline outer loops, unroll inner loops
├── Pipeline: Overlaps iterations in time (1 result per II cycles)
└── Unroll: Replicates in space (factor× resources)

Storage Selection

Array size?
├── Very small (< 64 elements) → LUTRAM or registers
├── Medium (64 - 4K elements) → BRAM
└── Large (> 4K elements) → URAM or multiple BRAM
