Interface Selection

Question: Which interface should I use for this port?

Category: Interface

Decision Tree

What type of data?
├── Large array/buffer
│   ├── Accessed once, sequentially → axis (streaming)
│   └── Random access or reuse → m_axi (memory-mapped)
├── Scalar value
│   └── Use s_axilite (register)
└── Control signals
    └── Use s_axilite port=return

Interface Comparison

Interface Bandwidth Latency Access Pattern Use Case
m_axi High (DDR ~19GB/s, HBM ~460GB/s) Higher Random or sequential External memory
axis High (sustained) Lower Sequential only Streaming data
s_axilite Low Low Register R/W Scalars, control

m_axi (AXI4 Master)

Memory-mapped interface for accessing external memory (DDR, HBM).

When to Use

  • Accessing external memory (DDR, HBM)
  • Large data transfers
  • Random access patterns
  • Data reuse (read multiple times)

When NOT to Use

  • Small scalar values
  • Streaming data accessed once
  • Low-latency requirements

Example

void kernel(int* data, int size) {
#pragma HLS INTERFACE m_axi port=data depth=1024 offset=slave bundle=gmem
#pragma HLS INTERFACE s_axilite port=size
#pragma HLS INTERFACE s_axilite port=return

    for (int i = 0; i < size; i++) {
        data[i] = data[i] * 2;  // Random access OK
    }
}

Key Parameters

Parameter Description
depth=N Expected array size (for co-sim)
offset=slave Address from s_axilite register
bundle=name Group ports on same AXI interface
max_read_burst_length Max burst for reads (default: 16)
max_write_burst_length Max burst for writes (default: 16)

axis (AXI4-Stream)

Streaming interface for sequential data without addressing.

When to Use

  • Streaming data (video, audio, network)
  • Kernel-to-kernel connections
  • Data processed once, sequentially
  • Low-latency streaming

When NOT to Use

  • Random access needed
  • Data needs to be reused
  • Need to seek/skip elements

Example

void kernel(hls::stream<ap_axis<32,1,1,1>>& in,
            hls::stream<ap_axis<32,1,1,1>>& out) {
#pragma HLS INTERFACE axis port=in
#pragma HLS INTERFACE axis port=out
#pragma HLS INTERFACE s_axilite port=return

    ap_axis<32,1,1,1> pkt;
    while (!in.empty()) {
        pkt = in.read();
        pkt.data *= 2;
        out.write(pkt);
    }
}

Key Parameters

Parameter Description
register_mode=both Add registers for timing
register_mode=off No register insertion

s_axilite (AXI4-Lite Slave)

Register-based interface for control and scalar values.

When to Use

  • Scalar arguments (size, config values)
  • Control/status registers
  • Kernel start/done signaling (port=return)

When NOT to Use

  • Large data transfers
  • High bandwidth requirements
  • Array data

Example

void kernel(int* data, int size, int threshold) {
#pragma HLS INTERFACE m_axi port=data
#pragma HLS INTERFACE s_axilite port=size bundle=control
#pragma HLS INTERFACE s_axilite port=threshold bundle=control
#pragma HLS INTERFACE s_axilite port=return bundle=control
    // ...
}

Special: port=return

Controls kernel execution: - ap_start - Host writes to start kernel - ap_done - Kernel sets when complete - ap_idle - Kernel sets when idle - ap_ready - Kernel ready for input

Add autorestart for continuous execution:

#pragma HLS INTERFACE s_axilite port=return autorestart
