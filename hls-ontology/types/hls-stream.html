hls::stream

FIFO-based streaming channel for dataflow communication between functions.

Header

#include <hls_stream.h>

Syntax

hls::stream<T> channel;
hls::stream<T> channel("name");  // Named stream (for debugging)
Parameter Description
T Data type to stream (any type: int, struct, hls::vector, etc.)

Methods

Method Return Description
read() T Blocking read - waits until data available
write(T data) void Blocking write - waits until space available
empty() bool Check if stream is empty
full() bool Check if stream is full
size() size_t Number of elements currently in stream
read_nb(T& data) bool Non-blocking read - returns false if empty
write_nb(T data) bool Non-blocking write - returns false if full

Basic Example

#include <hls_stream.h>

void producer(hls::stream<int>& out, int n) {
    for (int i = 0; i < n; i++) {
        out.write(i);  // Blocking write
    }
}

void consumer(hls::stream<int>& in, int* result, int n) {
    for (int i = 0; i < n; i++) {
        result[i] = in.read();  // Blocking read
    }
}

void top(int* result, int n) {
    hls::stream<int> channel;

#pragma HLS DATAFLOW
    producer(channel, n);
    consumer(channel, result, n);
}

Streaming Vectors

Combine hls::stream with hls::vector for high-throughput pipelines:

#include <hls_stream.h>
#include <hls_vector.h>

typedef hls::vector<uint32_t, 16> vecOf16Words;  // 512 bits

void load(vecOf16Words* mem, hls::stream<vecOf16Words>& out, int n) {
    for (int i = 0; i < n; i++) {
        out.write(mem[i]);  // Write 64 bytes per iteration
    }
}

void compute(hls::stream<vecOf16Words>& in,
             hls::stream<vecOf16Words>& out, int n) {
    for (int i = 0; i < n; i++) {
        vecOf16Words t = in.read();
        out.write(t * 3);  // Element-wise multiply all 16 values
    }
}

Non-Blocking Operations

Use non-blocking methods when you can't guarantee data availability:

void process(hls::stream<int>& in, hls::stream<int>& out) {
    int data;

    // Non-blocking read
    if (in.read_nb(data)) {
        // Data was available
        out.write(data * 2);
    }

    // Or check first
    if (!in.empty()) {
        data = in.read();
        out.write(data * 2);
    }
}

Stream Depth Control

Set FIFO depth with pragma:

hls::stream<int> channel;
#pragma HLS STREAM variable=channel depth=32

// Or in function signature
void func(hls::stream<int>& in) {
#pragma HLS INTERFACE mode=ap_fifo port=in depth=64
}
Depth Effect
Small (2-8) Less BRAM, may cause stalls
Medium (16-64) Good balance
Large (128+) More buffering, more BRAM

When to Use

Use Case Recommendation
Dataflow pipeline stages Yes - primary use case
Producer-consumer patterns Yes
Streaming data processing Yes
Random access needed No - use hls::stream_of_blocks
Need to peek without consuming No - streams are destructive read

Common Pitfalls

Pitfall Symptom Solution
Mismatched read/write counts Deadlock Ensure producer writes = consumer reads
Multiple readers Compile error Each stream: exactly 1 reader
Multiple writers Compile error Each stream: exactly 1 writer
Reading empty stream Deadlock (blocking) Use empty() or read_nb()
Missing DATAFLOW pragma Sequential execution Add #pragma HLS DATAFLOW
