ap_int and ap_uint

Arbitrary-precision integer types with exact bit-width control.

Header

#include <ap_int.h>

Syntax

ap_int<W>  signed_val;    // Signed integer, W bits
ap_uint<W> unsigned_val;  // Unsigned integer, W bits
Parameter Description
W Bit width (1 to 32768)

Why Use Arbitrary Precision?

Native C++ Problem ap_int/ap_uint Solution
int (32 bits) Wastes resources if you need 12 bits ap_int<12> - exact 12 bits
char (8 bits) Can't represent 10-bit value ap_uint<10> - exact 10 bits
Overflow Silent wraparound Controlled overflow modes

Basic Operations

All standard integer operations are supported:

ap_int<8> a = 100;
ap_int<8> b = 25;

// Arithmetic
ap_int<9> sum = a + b;      // 9 bits to prevent overflow
ap_int<16> prod = a * b;    // 16 bits for multiply
ap_int<8> diff = a - b;
ap_int<8> quot = a / b;
ap_int<8> rem = a % b;

// Comparison
bool eq = (a == b);
bool lt = (a < b);

// Bitwise
ap_int<8> and_result = a & b;
ap_int<8> or_result = a | b;
ap_int<8> xor_result = a ^ b;
ap_int<8> not_result = ~a;

// Shift
ap_int<8> lshift = a << 2;
ap_int<8> rshift = a >> 2;

Bit Manipulation

Range Selection (Slicing)

ap_uint<32> val = 0xABCD1234;

// Extract bits [15:8] (second byte)
ap_uint<8> byte1 = val.range(15, 8);  // = 0x12

// Extract bits [31:16] (upper half)
ap_uint<16> upper = val.range(31, 16);  // = 0xABCD

// Modify a range
val.range(7, 0) = 0xFF;  // val = 0xABCD12FF

Single Bit Access

ap_uint<8> val = 0b10101010;

bool bit3 = val[3];      // Read bit 3 (= 1)
val[0] = 1;              // Set bit 0
val.set_bit(7, 0);       // Clear bit 7

Concatenation

ap_uint<8> high = 0xAB;
ap_uint<8> low = 0xCD;

ap_uint<16> combined = (high, low);  // = 0xABCD

Type Conversion

ap_int<12> ap_val = 1000;

// To native types
int native_int = ap_val.to_int();
long native_long = ap_val.to_long();
double native_double = ap_val.to_double();

// From native types
ap_int<16> from_int = 12345;
ap_uint<32> from_hex = 0xDEADBEEF;

// String conversion
ap_uint<8> from_bin("10101010", 2);   // Binary
ap_uint<8> from_hex_str("FF", 16);    // Hex

Useful Methods

Method Description
length() Get bit width (compile-time constant)
to_int() Convert to native int
to_uint() Convert to native unsigned int
to_long() Convert to native long
range(hi, lo) Extract bit slice
test(i) Test if bit i is set
set(i) Set bit i to 1
clear(i) Set bit i to 0
reverse() Reverse bit order
and_reduce() AND all bits (returns 1 if all bits are 1)
or_reduce() OR all bits (returns 1 if any bit is 1)
xor_reduce() XOR all bits (returns parity)

Reduce Operations

Reduce operations combine all bits using a logic operation:

ap_uint<8> val = 0xFF;  // All ones

bool all_ones = val.and_reduce();   // true (all bits are 1)
bool non_zero = val.or_reduce();    // true (at least one bit is 1)
bool parity = val.xor_reduce();     // false (even number of 1s)

// Common use cases:
ap_uint<8> flags = 0b10101010;
if (flags.or_reduce()) {
    // At least one flag is set
}

ap_uint<32> data = 0xDEADBEEF;
bool parity_bit = data.xor_reduce();  // For error detection

Common Patterns

Typedef for Readability

// Define meaningful type names
typedef ap_int<6> coeff_t;
typedef ap_int<12> accum_t;
typedef ap_uint<10> addr_t;
typedef ap_uint<1> flag_t;

// Use in code
coeff_t coefficients[64];
accum_t sum = 0;
addr_t address = base + offset;

Arithmetic Width Rules

To prevent overflow, size result types according to these formulas:

Operation Result Width Formula Example
Multiply W1 + W2 ap_int<6> * ap_int<12> → ap_int<18>
Add/Subtract max(W1, W2) + 1 ap_int<6> + ap_int<12> → ap_int<13>
Divide W_dividend ap_int<22> / ap_int<6> → ap_int<22>
Modulo W_divisor ap_int<33> % ap_int<6> → ap_int<6> 
ap_int<6> a = 31;
ap_int<12> b = 2047;

ap_int<18> prod = a * b;    // 6 + 12 = 18 bits (safe)
ap_int<13> sum = a + b;     // max(6,12) + 1 = 13 bits (safe)
ap_int<22> c = 1000000;
ap_int<22> quot = c / a;    // Dividend width preserved
ap_int<6> rem = c % a;      // Divisor width preserved

Safe Casting for Overflow Prevention

When the result type matches input type, cast to wider type before the operation:

ap_int<18> a = 100000;
ap_int<18> b = 100000;

// WRONG: Overflow! 18-bit can't hold 18+18=36 bit result
ap_int<18> bad = a * b;

// CORRECT: Cast to wider type before multiply
ap_int<36> good = (ap_int<36>)a * (ap_int<36>)b;

This pattern is essential when you need the full-precision result.

Address Calculation

typedef ap_uint<32> addr_t;
typedef ap_uint<12> offset_t;

addr_t base = 0x1000;
offset_t offset = 0x100;
addr_t final_addr = base + offset;

When to Use

Use Case Recommendation
Exact bit-width control Yes - primary use case
Resource optimization Yes - avoid wasted bits
Bit manipulation Yes - range/concat support
Interface matching Yes - match external signals
Complex arithmetic Consider ap_fixed for fractional

ap_int vs ap_uint

Type Range for W bits Use Case
ap_int<W> -2^(W-1) to 2^(W-1)-1 Signed values
ap_uint<W> 0 to 2^W - 1 Unsigned values, addresses 
ap_int<8> signed_val;   // Range: -128 to 127
ap_uint<8> unsigned_val; // Range: 0 to 255
