ap_axis and ap_axiu

AXI-Stream packet types with sideband signals for streaming interfaces.

Header

#include <ap_axi_sdata.h>

Syntax

ap_axis<D, U, TI, TD>  signed_packet;    // Signed data
ap_axiu<D, U, TI, TD> unsigned_packet;   // Unsigned data (most common)
Parameter Description
D Data width in bits (TDATA)
U User signal width (TUSER)
TI ID signal width (TID)
TD Destination signal width (TDEST)

Packet Structure

ap_axiu<32, 2, 5, 6> packet;
// Creates a struct with:

struct {
    ap_uint<32> data;   // TDATA - payload
    ap_uint<4>  keep;   // TKEEP - byte enables (D/8 bits)
    ap_uint<4>  strb;   // TSTRB - byte strobes (D/8 bits)
    ap_uint<2>  user;   // TUSER - user sideband
    ap_uint<1>  last;   // TLAST - end of packet
    ap_uint<5>  id;     // TID - stream ID
    ap_uint<6>  dest;   // TDEST - routing
};

AXI-Stream Signal Mapping

              ┌─────────────────────────────────────┐
              │       AXI-Stream Packet             │
              ├─────────────────────────────────────┤
  TDATA[31:0] │  data   (32 bits payload)          │
  TKEEP[3:0]  │  keep   (which bytes are valid)    │
  TSTRB[3:0]  │  strb   (which bytes are data)     │
  TUSER[1:0]  │  user   (user-defined sideband)    │
  TLAST       │  last   (1 = end of packet)        │
  TID[4:0]    │  id     (stream identifier)        │
  TDEST[5:0]  │  dest   (routing info)             │
              └─────────────────────────────────────┘

Common Configurations

Configuration Use Case
ap_axiu<32, 0, 0, 0> Simple 32-bit stream, no sideband
ap_axiu<64, 0, 0, 0> 64-bit data stream
ap_axiu<32, 2, 5, 6> Full AXI4-Stream with routing
ap_axiu<512, 0, 0, 0> Wide bus for high bandwidth

Basic Usage

Creating and Sending Packets

#include <ap_axi_sdata.h>
#include <hls_stream.h>

typedef ap_axiu<32, 0, 0, 0> pkt;

void send_packet(hls::stream<pkt>& out, int value, bool is_last) {
    pkt p;
    p.data = value;
    p.keep = 0xF;     // All 4 bytes valid
    p.strb = 0xF;     // All 4 bytes are data
    p.last = is_last; // End of packet marker
    out.write(p);
}

Receiving and Processing Packets

void receive_packet(hls::stream<pkt>& in, int* result) {
    pkt p = in.read();

    // Extract data
    int value = p.data;

    // Check end of packet
    if (p.last) {
        // Handle end of packet
    }

    *result = value;
}

Complete Example

#include <ap_axi_sdata.h>
#include <hls_stream.h>

#define DWIDTH 32
typedef ap_axiu<DWIDTH, 2, 5, 6> pkt;

void stream_processor(hls::stream<pkt>& in,
                      hls::stream<pkt>& out,
                      int add_value) {
#pragma HLS INTERFACE mode=axis port=in
#pragma HLS INTERFACE mode=axis port=out
#pragma HLS INTERFACE mode=s_axilite port=add_value
#pragma HLS INTERFACE mode=s_axilite port=return

    bool eos = false;

    while (!eos) {
#pragma HLS PIPELINE II=1
        // Read input packet
        pkt t_in = in.read();

        // Process data
        pkt t_out;
        t_out.data = t_in.data + add_value;
        t_out.keep = t_in.keep;       // Preserve byte enables
        t_out.strb = t_in.strb;
        t_out.user = t_in.user;       // Pass through user signal
        t_out.last = t_in.last;       // Preserve last flag
        t_out.id = t_in.id;
        t_out.dest = t_in.dest;

        // Write output packet
        out.write(t_out);

        // Check for end of stream
        eos = t_in.last;
    }
}

Field Details

TKEEP (keep)

Indicates which bytes in TDATA are valid:

pkt p;
p.data = 0xAABBCCDD;
p.keep = 0xF;   // 0b1111 - all 4 bytes valid
p.keep = 0x3;   // 0b0011 - only bytes 0,1 valid (0xCCDD)
p.keep = 0xC;   // 0b1100 - only bytes 2,3 valid (0xAABB)

TLAST (last)

Marks end of a packet/transaction:

// Sending a 3-word packet
for (int i = 0; i < 3; i++) {
    pkt p;
    p.data = values[i];
    p.keep = 0xF;
    p.last = (i == 2);  // Set last on final word
    out.write(p);
}

TUSER (user)

User-defined sideband data:

// Example: Use TUSER for packet type
#define PKT_TYPE_DATA   0
#define PKT_TYPE_CMD    1
#define PKT_TYPE_STATUS 2

pkt p;
p.user = PKT_TYPE_CMD;

ap_axis vs ap_axiu

Type Data Field Type Use Case
ap_axis ap_int<D> (signed) Signed data streams
ap_axiu ap_uint<D> (unsigned) Most common, raw bytes

Interface Pragma

void kernel(hls::stream<pkt>& in, hls::stream<pkt>& out) {
#pragma HLS INTERFACE mode=axis port=in
#pragma HLS INTERFACE mode=axis port=out
    // ...
}

The mode=axis pragma creates full AXI4-Stream interface with all signals.

Test Bench

#include "kernel.h"

int main() {
    hls::stream<pkt> in, out;

    // Create test packets
    for (int i = 0; i < 10; i++) {
        pkt p;
        p.data = i * 100;
        p.keep = 0xF;
        p.strb = 0xF;
        p.user = 0;
        p.last = (i == 9);  // Last packet
        p.id = 0;
        p.dest = 0;
        in.write(p);
    }

    // Run kernel
    stream_processor(in, out, 1);

    // Verify output
    for (int i = 0; i < 10; i++) {
        pkt p = out.read();
        if (p.data != i * 100 + 1) {
            return 1;  // Error
        }
    }

    return 0;  // Pass
}
