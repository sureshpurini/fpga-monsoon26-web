hls::axis

Modern AXI-Stream packet type with flexible data type support. Preferred over ap_axis/ap_axiu for new designs.

Header

#include <hls_stream.h>

Syntax

hls::axis<T, WUser, WId, WDest>
Parameter Description Default
T Data type (any synthesizable type) Required
WUser TUSER width (0 to disable) 0
WId TID width (0 to disable) 0
WDest TDEST width (0 to disable) 0

Fields

Field Type Description
data T Payload of arbitrary type
keep auto Byte enables (auto-sized)
last bool End of packet marker (TLAST)
user ap_uint<WUser> User sideband (if WUser > 0)
id ap_uint<WId> Stream ID (if WId > 0)
dest ap_uint<WDest> Destination (if WDest > 0)

Basic Example

#include <hls_stream.h>

typedef hls::axis<int, 0, 0, 0> pkt_t;

void process(hls::stream<pkt_t>& in, hls::stream<pkt_t>& out) {
#pragma HLS INTERFACE axis port=in
#pragma HLS INTERFACE axis port=out

    pkt_t pkt = in.read();
    pkt.data = pkt.data * 2;
    pkt.last = true;  // Mark end of packet
    out.write(pkt);
}

With Complex Types

hls::axis accepts any synthesizable type, unlike ap_axis which requires fixed bit-width:

#include <hls_stream.h>
#include <complex>

// Complex number streaming
typedef hls::axis<std::complex<short>, 0, 0, 0> cplx_pkt_t;

void complex_scale(hls::stream<cplx_pkt_t>& in,
                   hls::stream<cplx_pkt_t>& out) {
#pragma HLS INTERFACE axis port=in
#pragma HLS INTERFACE axis port=out

    cplx_pkt_t pkt = in.read();
    pkt.data = pkt.data * std::complex<short>(2, 0);
    pkt.last = true;
    out.write(pkt);
}

With Structs

struct pixel_t {
    uint8_t r, g, b, a;
};

typedef hls::axis<pixel_t, 0, 0, 0> pixel_pkt_t;

void brighten(hls::stream<pixel_pkt_t>& in,
              hls::stream<pixel_pkt_t>& out) {
#pragma HLS INTERFACE axis port=in
#pragma HLS INTERFACE axis port=out

    pixel_pkt_t pkt = in.read();
    pkt.data.r = std::min(255, pkt.data.r + 50);
    pkt.data.g = std::min(255, pkt.data.g + 50);
    pkt.data.b = std::min(255, pkt.data.b + 50);
    out.write(pkt);
}

With hls::vector (Wide Data)

#include <hls_vector.h>

typedef hls::vector<int, 16> vec16;
typedef hls::axis<vec16, 4, 0, 0> wide_pkt_t;  // 512-bit data + 4-bit user

void wide_process(hls::stream<wide_pkt_t>& in,
                  hls::stream<wide_pkt_t>& out) {
#pragma HLS INTERFACE axis port=in
#pragma HLS INTERFACE axis port=out

    wide_pkt_t pkt = in.read();
    pkt.data = pkt.data * 2;  // Scale all 16 elements
    pkt.user = 0xF;           // Set user field
    pkt.last = true;
    out.write(pkt);
}

With Side Channels

// Full side channel usage
typedef hls::axis<int, 4, 2, 3> full_pkt_t;
// 4-bit TUSER, 2-bit TID, 3-bit TDEST

void route(hls::stream<full_pkt_t>& in,
           hls::stream<full_pkt_t>& out0,
           hls::stream<full_pkt_t>& out1) {
#pragma HLS INTERFACE axis port=in
#pragma HLS INTERFACE axis port=out0
#pragma HLS INTERFACE axis port=out1

    full_pkt_t pkt = in.read();

    // Route based on destination field
    if (pkt.dest == 0) {
        out0.write(pkt);
    } else {
        out1.write(pkt);
    }
}

Comparison with ap_axis

Aspect hls::axis ap_axis/ap_axiu
Data type Any synthesizable Fixed bit-width only
Flexibility High Limited
Preferred New designs Legacy compatibility
Header hls_stream.h ap_axi_sdata.h

When to Use

Use Case Recommendation
New AXI-Stream designs Yes - preferred
Complex/struct data Yes
Wide data (vectors) Yes
Legacy code Consider ap_axis
Simple streaming Consider plain hls::stream

Related Types

  • ap_axis / ap_axiu - Legacy AXI-Stream types
  • hls::stream - Simple streaming without side channels
  • hls::vector - Wide data for axis packets
