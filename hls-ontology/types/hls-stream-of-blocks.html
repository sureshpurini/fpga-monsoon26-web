hls::stream_of_blocks

Block-level streaming with random access within blocks. Combines the pipelining benefits of streaming with the flexibility of random access.

Header

#include <hls_streamofblocks.h>

Syntax

typedef data_t block_t[BLOCK_SIZE];
hls::stream_of_blocks<block_t> channel;
Parameter Description
block_t Block type (typically array typedef)

Lock Types

Access to blocks requires RAII locks:

Type Description
hls::write_lock<block_t> Acquire block for writing
hls::read_lock<block_t> Acquire block for reading

Locks are released automatically when they go out of scope.

Basic Example

#include <hls_streamofblocks.h>

#define BLOCK_SIZE 64
typedef int block_t[BLOCK_SIZE];

void producer(hls::stream_of_blocks<block_t>& out, int* input) {
    // Acquire write lock on a block
    hls::write_lock<block_t> lock(out);

    for (int i = 0; i < BLOCK_SIZE; i++) {
        lock[i] = input[i];  // Random access write
    }
    // Block sent automatically when lock goes out of scope
}

void consumer(hls::stream_of_blocks<block_t>& in, int* output) {
    // Acquire read lock on a block
    hls::read_lock<block_t> lock(in);

    for (int i = 0; i < BLOCK_SIZE; i++) {
        output[i] = lock[i];  // Random access read
    }
    // Block released automatically
}

void top(int* input, int* output) {
    hls::stream_of_blocks<block_t> channel;

#pragma HLS DATAFLOW
    producer(channel, input);
    consumer(channel, output);
}

Random Access Within Blocks

Unlike hls::stream, you can access elements in any order within a block:

void process(hls::stream_of_blocks<block_t>& in,
             hls::stream_of_blocks<block_t>& out) {
    hls::read_lock<block_t> in_lock(in);
    hls::write_lock<block_t> out_lock(out);

    // Access in any order - not sequential!
    out_lock[0] = in_lock[BLOCK_SIZE-1];  // Last to first
    out_lock[BLOCK_SIZE-1] = in_lock[0];  // First to last

    // Middle elements
    for (int i = 1; i < BLOCK_SIZE-1; i++) {
        out_lock[i] = in_lock[i] * 2;
    }
}

Diamond Pattern with Blocks

typedef int block_t[NUM_ELEMENTS];

void funcA(hls::stream_of_blocks<block_t>& in,
           hls::stream_of_blocks<block_t>& out1,
           hls::stream_of_blocks<block_t>& out2) {
    hls::read_lock<block_t> inL(in);
    hls::write_lock<block_t> outL1(out1);
    hls::write_lock<block_t> outL2(out2);

    for (int i = 0; i < NUM_ELEMENTS; i++) {
        outL1[i] = inL[i];
        outL2[i] = inL[i];
    }
}

void top(...) {
    hls::stream_of_blocks<block_t> c1, c2, c3;

#pragma HLS DATAFLOW
    funcA(in, c1, c2);
    funcB(c1, c3);
    funcC(c2, c3, out);
}

When to Use

Use Case Recommendation
Need random access within data unit Yes
Block-level synchronization Yes
Image tile processing Yes
Matrix operations on blocks Yes
Pure element-by-element streaming No - use hls::stream
No random access needed No - use hls::stream

Comparison with hls::stream

Aspect hls::stream hls::stream_of_blocks
Access Sequential (FIFO) Random within block
Granularity Element Block
Lock required No Yes (read_lock/write_lock)
Use case Streaming Block processing

Related Types
