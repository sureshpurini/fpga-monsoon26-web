hls::read_lock / hls::write_lock

RAII lock types for accessing blocks in hls::stream_of_blocks. Acquire access when constructed, release when destroyed (scope exit).

Header

#include <hls_streamofblocks.h>

Syntax

// For reading from stream_of_blocks
hls::read_lock<block_t> lock(stream);

// For writing to stream_of_blocks
hls::write_lock<block_t> lock(stream);
Parameter Description
block_t Block type (must match stream_of_blocks template parameter)
stream The hls::stream_of_blocks<block_t> to access

hls::write_lock

Acquires an empty block for writing. Block is sent when lock is destroyed.

typedef int block_t[64];
hls::stream_of_blocks<block_t> channel;

void producer(...) {
    // Acquire empty block
    hls::write_lock<block_t> lock(channel);

    // Random access write
    for (int i = 0; i < 64; i++) {
        lock[i] = compute(i);
    }

    // Block automatically sent when lock goes out of scope
}

Methods

Method Return Description
operator[](size_t i) T& Random access write to element i

hls::read_lock

Acquires a block for reading. Block is released when lock is destroyed.

typedef int block_t[64];
hls::stream_of_blocks<block_t> channel;

void consumer(...) {
    // Acquire block with data
    hls::read_lock<block_t> lock(channel);

    // Random access read
    for (int i = 0; i < 64; i++) {
        int val = lock[i];
        process(val);
    }

    // Block automatically released when lock goes out of scope
}

Methods

Method Return Description
operator[](size_t i) const T& Random access read from element i

Complete Example

#include <hls_streamofblocks.h>

#define BLOCK_SIZE 64
typedef int block_t[BLOCK_SIZE];

void producer(hls::stream_of_blocks<block_t>& out, int* input, int blocks) {
    for (int b = 0; b < blocks; b++) {
        hls::write_lock<block_t> lock(out);  // Get empty block

        for (int i = 0; i < BLOCK_SIZE; i++) {
            lock[i] = input[b * BLOCK_SIZE + i];
        }
        // lock released, block sent
    }
}

void process(hls::stream_of_blocks<block_t>& in,
             hls::stream_of_blocks<block_t>& out, int blocks) {
    for (int b = 0; b < blocks; b++) {
        hls::read_lock<block_t> in_lock(in);    // Get data block
        hls::write_lock<block_t> out_lock(out); // Get empty block

        // Random access in both directions
        for (int i = 0; i < BLOCK_SIZE; i++) {
            out_lock[i] = in_lock[BLOCK_SIZE - 1 - i];  // Reverse
        }
        // Both locks released at end of iteration
    }
}

void consumer(hls::stream_of_blocks<block_t>& in, int* output, int blocks) {
    for (int b = 0; b < blocks; b++) {
        hls::read_lock<block_t> lock(in);  // Get data block

        for (int i = 0; i < BLOCK_SIZE; i++) {
            output[b * BLOCK_SIZE + i] = lock[i];
        }
        // lock released, block freed
    }
}

RAII Behavior

Locks follow RAII (Resource Acquisition Is Initialization):

void example(hls::stream_of_blocks<block_t>& channel) {
    // Block acquired here
    hls::write_lock<block_t> lock(channel);

    lock[0] = 1;
    lock[1] = 2;

    if (condition) {
        return;  // Block sent here (early return)
    }

    lock[2] = 3;
    // Block sent here (normal scope exit)
}

When to Use

Use Case Type
Writing to stream_of_blocks hls::write_lock
Reading from stream_of_blocks hls::read_lock
Element-by-element streaming Neither - use hls::stream

Common Pitfalls

Pitfall Solution
Forgetting lock goes out of scope in loop Intentional - one block per iteration
Holding lock too long Keep lock scope minimal
Using with hls::stream Only works with stream_of_blocks

Related Types

  • hls::stream_of_blocks - Block-level streaming
  • hls::stream - Element-by-element streaming (no locks needed)
