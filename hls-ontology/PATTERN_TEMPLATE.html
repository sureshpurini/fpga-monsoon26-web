Test Bench Generation Guidelines

REQUIRED SECTION - Every pattern must have this for verification

Test Bench Template

#include "[kernel].h"
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    // 1. Declare test data (match kernel interface)
    data_t input[N], output[N];

    // 2. Initialize test inputs
    for (int i = 0; i < N; i++) {
        input[i] = (data_t)i;  // or pattern-based initialization
    }

    // 3. Open results file
    ofstream FILE;
    FILE.open("result.dat");

    // 4. Execute DUT (multiple iterations recommended)
    for (int iter = 0; iter < 3; iter++) {
        kernel_name(input, output);

        // 5. Capture outputs
        for (int i = 0; i < N; i++) {
            FILE << output[i] << endl;
        }
    }
    FILE.close();

    // 6. Verify against golden reference
    int retval = system("diff --brief -w result.dat result.golden.dat");
    if (retval != 0) {
        cout << "Test failed!" << endl;
        return 1;
    }
    cout << "Test passed!" << endl;
    return 0;  // 0 = PASS
}

Interface-Specific Templates

Array Interface

Vector Interface

std::vector<vecType> input(SIZE), output(SIZE);

Stream Interface

hls::stream<data_t> input, output;
// Write inputs
for (int i = 0; i < N; i++) input.write(i);
// Execute
kernel_name(input, output);
// Read outputs
for (int i = 0; i < N; i++) result[i] = output.read();

Autorestart Interface

#include "hls_task.h"
data_t input[N * NUM_ITER], output[N * NUM_ITER];
hls::autorestart run_top(NUM_ITER, kernel_name, input, output);

Verification Methods

Method When to Use
File diff (diff result.dat result.golden.dat) Standard approach, pre-computed golden
In-memory comparison When golden can be computed in test bench
Tolerance-based Floating-point results

Requirement Purpose

Match kernel interface Arrays, vectors, or streams as needed
Golden reference file Pre-computed expected outputs
