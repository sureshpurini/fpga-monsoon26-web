Memory Interface Patterns

This guide covers M-AXI memory interfaces, burst optimization, local memory patterns, and storage selection.

Overview

Memory interfaces in HLS fall into two categories:

Category Interface Use Case
External Memory M-AXI DDR, HBM access via burst transfers
Local Memory BRAM, URAM, LUTRAM On-chip arrays, buffers

M-AXI Interface Basics

Basic M-AXI Configuration

void kernel(int* a, int size) {
#pragma HLS INTERFACE m_axi port=a depth=1024 offset=slave bundle=gmem \
    max_read_burst_length=256 max_write_burst_length=256

#pragma HLS INTERFACE s_axilite port=a      // Address register
#pragma HLS INTERFACE s_axilite port=size   // Size parameter
#pragma HLS INTERFACE s_axilite port=return // Control
}

Key M-AXI Parameters

Parameter Description Default
depth Array size for co-simulation Required
offset Address mode: slave, direct, off slave
bundle Port grouping name gmem
max_read_burst_length Max elements per read burst 16
max_write_burst_length Max elements per write burst 16
max_widen_bitwidth Port width for vectorization 32
latency Expected memory latency -
num_read_outstanding Outstanding read transactions 16
num_write_outstanding Outstanding write transactions 16

Burst Optimization

Auto-Burst (Sequential Access)

HLS automatically infers bursts for sequential loop access:

void auto_burst(int* mem, int buf[N]) {
#pragma HLS INTERFACE m_axi port=mem depth=N

    // Sequential access → auto-burst inferred
    for (int i = 0; i < N; i++) {
#pragma HLS PIPELINE II=1
        buf[i] = mem[i];  // Burst read
    }
}

Manual Burst with hls::burst_maxi

When auto-burst fails (complex indexing, conditionals), use explicit burst control:

#include "hls_burst_maxi.h"

void manual_burst(hls::burst_maxi<int> in, hls::burst_maxi<int> out, int size) {
#pragma HLS INTERFACE m_axi port=in depth=512 latency=32 bundle=gmem0
#pragma HLS INTERFACE m_axi port=out depth=512 latency=32 bundle=gmem1

    int buf[MAX_SIZE];

    // Explicit burst read
    in.read_request(0, size);        // Request: offset, length
    for (int i = 0; i < size; i++) {
#pragma HLS PIPELINE II=1
        buf[i] = in.read();          // Read from burst buffer
    }

    // Process...

    // Explicit burst write
    out.write_request(0, size);      // Request: offset, length
    for (int i = 0; i < size; i++) {
#pragma HLS PIPELINE II=1
        out.write(buf[i]);           // Write to burst buffer
    }
    out.write_response();            // Wait for completion
}

hls::burst_maxi API:

Method Purpose
read_request(offset, len) Request burst read
read() Get next element from buffer
write_request(offset, len) Request burst write
write(data) Add element to write buffer
write_response() Wait for write acknowledgment

Port Widening

Widen M-AXI port for higher bandwidth:

void wide_port(int a[N], int b[N]) {
#pragma HLS INTERFACE m_axi port=a bundle=gmem max_widen_bitwidth=512
#pragma HLS INTERFACE m_axi port=b bundle=gmem

    for (int i = 0; i < N; i++) {
#pragma HLS PIPELINE II=1
        b[i] = a[i] + 100;
    }
}

Effect: 512-bit port transfers 16 x 32-bit integers per transaction.

Note: In Vivado IP flow, add to config:

config_interface -m_axi_max_widen_bitwidth 512
config_interface -m_axi_alignment_byte_size 64

Port Aliasing

When two M-AXI ports access the same memory:

#include <hls_fence.h>

void writer(hls::stream<int>& in, int* mem, hls::stream<bool>& done) {
#pragma HLS INLINE OFF
    for (int i = 0; i < SIZE; i++) {
#pragma HLS PIPELINE
        mem[i] = in.read();
    }
    hls::fence(mem, done);  // Ensure writes complete
    done.write(true);       // Signal completion
}

void reader(int* mem, hls::stream<int>& out, hls::stream<bool>& done) {
#pragma HLS INLINE OFF
    done.read();            // Wait for writer
    hls::fence(done, mem);  // Ensure signal before reads
    for (int i = 0; i < SIZE; i++) {
#pragma HLS PIPELINE
        out.write(mem[i]);
    }
}

void top(hls::stream<int>& in, int* memA, int* memB, hls::stream<int>& out) {
#pragma HLS INTERFACE m_axi port=memA bundle=axi1
#pragma HLS INTERFACE m_axi port=memB bundle=axi2
#pragma HLS ALIAS ports=memA,memB distance=0  // Same memory!

#pragma HLS DATAFLOW
    hls::stream<bool> sync;
    writer(in, memA, sync);
    reader(memB, out, sync);
}

Key elements: - #pragma HLS ALIAS tells HLS ports share memory - hls::fence(src, dst) orders memory operations - Stream acts as synchronization barrier

M-AXI Cache

For access patterns with data reuse:

void cached_access(const double* in, double* out, int size) {
#pragma HLS INTERFACE m_axi port=in bundle=aximm depth=1025 \
    max_read_burst_length=128 num_read_outstanding=256
#pragma HLS INTERFACE m_axi port=out bundle=aximm depth=1024

#pragma HLS cache port=in lines=1 depth=128

    for (int i = 0; i < size; i++) {
        out[i] = in[i] + in[i + 1];  // in[i+1] reused as in[i] next iteration
    }
}

Cache parameters: - lines: Number of cache lines (associativity) - depth: Elements per cache line

When to use: Overlapping access patterns (e.g., in[i] + in[i+1])

Local Memory Optimization

BRAM Dual-Port Access

Use both BRAM ports with UNROLL factor=2:

void dual_port(int a[N], int b[N], int c[N]) {
    int buf_a[CHUNK], buf_b[CHUNK], buf_c[CHUNK];

    // ... burst read ...

process:
    for (int j = 0; j < CHUNK; j++) {
#pragma HLS UNROLL factor=2  // Use both BRAM ports
        buf_c[j] = buf_a[j] + buf_b[j];
    }

    // ... burst write ...
}

Memory Bottleneck Fix (Shift Register)

When accessing multiple adjacent elements:

// PROBLEM: 3 reads per iteration = II=3
dout_t bad(din_t mem[N]) {
    dout_t sum = 0;
    for (int i = 2; i < N; i++)
        sum += mem[i] + mem[i-1] + mem[i-2];  // 3 reads!
    return sum;
}

// SOLUTION: Shift register = 1 read per iteration = II=1
dout_t good(din_t mem[N]) {
    din_t tmp0, tmp1, tmp2;
    dout_t sum = 0;

    tmp0 = mem[0];  // Prime the register
    tmp1 = mem[1];

    for (int i = 2; i < N; i++) {
        tmp2 = mem[i];              // Only 1 read
        sum += tmp2 + tmp1 + tmp0;
        tmp0 = tmp1;                // Shift
        tmp1 = tmp2;
    }
    return sum;
}

Storage Selection

BIND_STORAGE Options

static data_t buffer[SIZE];
#pragma HLS BIND_STORAGE variable=buffer type=ram_2p impl=uram
impl Size Ports Use When
lutram Small (distributed) Many Small arrays, many ports
bram 18Kb/36Kb blocks 1-2 Medium arrays, standard
uram 288Kb blocks 2 Large arrays (>36Kb)
uram_ecc 288Kb + ECC 2 Safety-critical

URAM Example

void uram_buffer(bool wren, bool rden, addr_t addrW, data_t datain,
                 addr_t addrR, data_t* dataout) {
#pragma HLS PIPELINE II=1

    static data_t buffer[NWORDS];
#pragma HLS DEPENDENCE variable=buffer inter WAR false  // Required for II=1
#pragma HLS BIND_STORAGE variable=buffer type=ram_2p impl=uram

    if (rden)
        *dataout = buffer[addrR];
    if (wren)
        buffer[addrW] = datain;
}

ROM Inference

Initialize lookup tables in sub-function for ROM inference:

// Init function - optimized away at synthesis
static void init_lut(int16_t table[256]) {
    for (int i = 0; i < 256; i++) {
        table[i] = (int16_t)(32768.0 * sin(M_PI * (i - 128) / 256.0));
    }
}

// Main function
void kernel(int16_t in[N], int32_t out[N]) {
    static int16_t lut[256];  // Becomes ROM

    init_lut(lut);  // Evaluated at compile time, disappears

    for (int i = 0; i < N; i++) {
#pragma HLS PIPELINE
        out[i] = (int32_t)in[i] * (int32_t)lut[in[i] & 0xFF];
    }
}

Key: Init function must be deterministic (no external inputs).

Decision Guide

Memory access pattern?
├── External memory (DDR/HBM)?
│   ├── Sequential access → Auto-burst (pointer)
│   ├── Complex indexing → hls::burst_maxi
│   ├── Two ports same memory → ALIAS + hls::fence
│   ├── Data reuse → #pragma HLS cache
│   └── Need more bandwidth → max_widen_bitwidth
│
└── Local array (on-chip)?
    ├── Large (>36Kb) → URAM
    ├── Medium → BRAM
    ├── Small, many ports → LUTRAM
    ├── Multiple adjacent reads → Shift register
    ├── Want 2x throughput → UNROLL factor=2
    └── Read-only computed values → ROM inference
