Streaming Interface Patterns (AXI-Stream)

This guide covers AXI-Stream interfaces, side channels, type selection, and common streaming patterns.

Overview

AXI-Stream (AXIS) provides high-throughput, low-latency streaming without addressing overhead. Data flows continuously with handshake signals (TVALID/TREADY).

Producer ──TDATA──→ Consumer
         ──TVALID──→
         ←TREADY───

Basic AXIS Interface

Array as Stream (Simplest)

void example(int A[50], int B[50]) {
#pragma HLS INTERFACE axis port=A  // Input stream
#pragma HLS INTERFACE axis port=B  // Output stream

    for (int i = 0; i < 50; i++) {
        B[i] = A[i] + 5;  // Converted to stream read/write
    }
}

Result: TDATA + TVALID/TREADY, no side channels.

hls::stream with AXIS

void example(hls::stream<int>& in, hls::stream<int>& out) {
#pragma HLS INTERFACE axis port=in
#pragma HLS INTERFACE axis port=out

    for (int i = 0; i < N; i++) {
#pragma HLS PIPELINE II=1
        out.write(in.read() + 5);
    }
}

Side Channel Types

Type Comparison

Type Data Type Side Channels Use Case
ap_axis<W,U,I,D> ap_int<W> (signed) All enabled Full-featured, signed data
ap_axiu<W,U,I,D> ap_uint<W> (unsigned) All enabled Full-featured, unsigned data
hls::axis<T,U,I,D> Any type T Configurable Custom data types (structs, complex)
hls::axis_user<W,flags> None Selective Metadata-only streams

Side Channel Signals

Signal Purpose When to Use
TDATA Payload data Always
TLAST End of packet/frame Variable-length packets
TKEEP Byte valid mask Partial words
TSTRB Data vs position byte Rare
TUSER User sideband Custom metadata
TID Stream identifier Interleaved streams
TDEST Routing destination Multi-destination

Type Usage Examples

ap_axis - All Side Channels

#include "ap_axi_sdata.h"

typedef ap_axis<32, 2, 5, 6> packet;
//              │   │  │  └── TDEST width (6 bits)
//              │   │  └───── TID width (5 bits)
//              │   └──────── TUSER width (2 bits)
//              └──────────── TDATA width (32 bits)

void example(hls::stream<packet>& in, hls::stream<packet>& out) {
#pragma HLS INTERFACE axis port=in
#pragma HLS INTERFACE axis port=out

    packet p = in.read();
    p.data = p.data + 5;    // TDATA (signed)
    p.keep = 0xF;           // TKEEP - all 4 bytes valid
    p.strb = 0xF;           // TSTRB
    p.user = p.user + 1;    // TUSER
    p.last = 1;             // TLAST - end of packet
    // p.id, p.dest also available
    out.write(p);
}

hls::axis - Custom Data Type

#include "ap_axi_sdata.h"

typedef hls::axis<std::complex<short>, 0, 0, 0> cplx_pkt;
//                └── Any C++ type!    │  │  └── TDEST (0=disabled)
//                                     │  └───── TID (0=disabled)
//                                     └──────── TUSER (0=disabled)

void example(hls::stream<cplx_pkt>& in, hls::stream<cplx_pkt>& out) {
#pragma HLS INTERFACE axis port=in
#pragma HLS INTERFACE axis port=out

    cplx_pkt p;
    do {
        p = in.read();
        p.data.real(p.data.real() + 5);  // Access complex fields
        p.data.imag(p.data.imag() + 1);
        out.write(p);
    } while (!p.last);  // TLAST always available
}

hls::axis_user - Selective Channels

typedef hls::axis_user<13, (AXIS_ENABLE_USER | AXIS_ENABLE_LAST)> packet;
//                     │    └── Flags: only TUSER and TLAST
//                     └─────── TUSER width (13 bits)

void example(hls::stream<packet>& in, hls::stream<packet>& out) {
#pragma HLS INTERFACE axis port=in
#pragma HLS INTERFACE axis port=out

    packet p = in.read();
    p.set_user(p.get_user() + 5);  // Accessor methods
    out.write(p);
}

Available flags: AXIS_ENABLE_USER, AXIS_ENABLE_LAST, AXIS_ENABLE_ID, AXIS_ENABLE_DEST

Array of Streams

Create multiple parallel AXIS interfaces:

#define M 3  // Number of channels

int dut(hls::stream<int> s_in[M], hls::stream<int> s_out[M]) {
#pragma HLS INTERFACE axis port=s_in   // Creates s_in_0, s_in_1, s_in_2
#pragma HLS INTERFACE axis port=s_out  // Creates s_out_0, s_out_1, s_out_2

    int sum = 0;
    for (int j = 0; j < M; j++) {
        for (int i = 0; i < DEPTH; i++) {
#pragma HLS PIPELINE II=1
            int val = s_in[j].read();
            s_out[j].write(val + 2);
            sum += val;
        }
    }
    return sum;
}

Port naming: stream_array[N] creates stream_array_0, stream_array_1, ... stream_array_N-1

AXIS to M-AXI Conversion

Receive streaming data and write to DDR with bursts:

typedef ap_axiu<64, 0, 0, 0> trans_pkt;

struct data {
    ap_int<64> data_field;
    ap_int<1> last;
};

void getinstream(hls::stream<trans_pkt>& in,
                 hls::stream<data>& out, hls::stream<int>& counts) {
    int count = 0;
    trans_pkt pkt;
    do {
#pragma HLS PIPELINE
        pkt = in.read();
        data d = {pkt.data, pkt.last};
        out.write(d);
        count++;
        if (count >= MAX_BURST || pkt.last) {
            counts.write(count);
            count = 0;
        }
    } while (!pkt.last);
}

void streamtoparallelwithburst(hls::stream<data>& in,
                               hls::stream<int>& counts,
                               ap_uint<64>* mem) {
    data val;
    do {
        int count = counts.read();
        for (int i = 0; i < count; i++) {
#pragma HLS PIPELINE
            val = in.read();
            mem[i] = val.data_field;
        }
        mem += count;
    } while (!val.last);
}

void top(hls::stream<trans_pkt>& in_stream, ap_uint<64>* out_mem) {
#pragma HLS INTERFACE axis register_mode=both port=in_stream
#pragma HLS INTERFACE m_axi max_write_burst_length=256 latency=10 \
    depth=1024 bundle=gmem0 port=out_mem

#pragma HLS DATAFLOW
    hls::stream<data, 4096> buf;
    hls::stream<int, 64> count;

    getinstream(in_stream, buf, count);
    streamtoparallelwithburst(buf, count, out_mem);
}

Pattern: 1. Read from AXIS, extract TLAST 2. Buffer with count for burst sizing 3. Write to M-AXI in bursts

Register Mode

Control pipeline register insertion for timing:

#pragma HLS INTERFACE axis register_mode=both port=in_stream
Mode Registers Latency Use When
both TDATA + TREADY +2 cycles Best timing (default)
forward TDATA only +1 cycle Moderate timing
reverse TREADY only +1 cycle Backpressure path
off None 0 cycles Lowest latency, timing risk

TLAST Handling

TLAST marks packet/frame boundaries:

// Reading with TLAST
packet p;
do {
    p = in.read();
    // Process p.data...
} while (!p.last);  // Exit on TLAST

// Writing with TLAST
for (int i = 0; i < N; i++) {
    packet p;
    p.data = compute(i);
    p.last = (i == N-1) ? 1 : 0;  // Set TLAST on last element
    out.write(p);
}

Decision Guide

Need streaming interface?
├── Simple data, no metadata → hls::stream<T> + axis pragma
├── Need TLAST for packets?
│   ├── Fixed-width data → ap_axis/ap_axiu
│   └── Custom data type → hls::axis<T>
├── Need TUSER/TID/TDEST?
│   ├── All side channels → ap_axis<W,U,I,D>
│   └── Selective channels → hls::axis_user<W,flags>
├── Multiple parallel channels → hls::stream<T> s[N]
└── Stream to memory → axis + DATAFLOW + m_axi
